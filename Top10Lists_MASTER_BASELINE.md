## 1. Architecture

### Hosting & runtime
- **Frontend:** Vercel. React SPA (Vite). Routing: react-router-dom (frozen).
- **Database / backend:** Supabase (PostgreSQL). Project ID: `wiotrvoirdgzfacuuiem`. One Supabase project for both staging and main.
- **Bot/SEO rendering:** Cloudflare is **deprecated**. (Legacy: Worker orange-truth-a103; do not add new Cloudflare dependencies.)
- **Production domain:** `www.top10lists.us` and `top10lists.us`.

### Key endpoints
- **Enrichment API:** `https://wiotrvoirdgzfacuuiem.supabase.co/functions/v1/enrichment-api`
- **Badge/artifact:** Vercel rewrites `/api/v1/badge/:agentId` and `/api/v1/badge/:agentId/verify` to Supabase `artifact-payload` and `artifact-verify`.
- **Sitemap:** Generated by Supabase function `generate-sitemap`. Authority URLs (/, /about/founder, /methodology, /faq, /ai-citation-whitepaper) priority 0.9–1.0; city/neighborhood list URLs priority 0.8.

### Routing
- **Law 1.2:** Static route manifest in `src/routes/manifest.tsx`. No conditionals, no nested `<Routes>`. Admin routes are flat; `AdminRouteGuard` blocks production hosts.
- **vercel.json:** Redirects `/admin` and `/admin/:path*` to `/404` when host is `www.top10lists.us` or `top10lists.us`. Rewrites for badge API, artifact, enrichment-api, bot HTML, etc. Staging: `X-Robots-Tag: noindex, nofollow`.

### Data flow
- **State licenses:** Primary discovery (AZ, CA, TX, FL, NY, CO). Monthly batch.
- **Zillow:** Apify memo23 actor; ~$0.50/agent; ratings, reviews, sales.
- **Exa/DeepSeek:** Zillow profile discovery, press; DeepSeek for Main tier synthesis.
- **Query limits:** Default 1,000 rows; always paginate for tables >1K.

- **Two branches, one Supabase:** `staging` and `main`. Both deploy to same Supabase. Direction is one-way only: **staging → main**. Never merge or deploy main into staging.
