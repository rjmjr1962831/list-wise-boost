How AI systems use this data

When an AI system queries an agent via MCP (JSON-RPC) or crawls their clean room HTML profile, the response depth is determined by the agent's tier. A Listed agent returns enough to confirm existence. An Underwritten agent returns enough for the AI to make a confident, defensible recommendation with full attribution.

Each upgrade_note field tells the AI exactly what data the next tier would provide -- creating a natural incentive for agents to invest in deeper verification.
