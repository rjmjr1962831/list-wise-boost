# Rule collision review (best-effort)
Note: This collision map is based on the master prompt and the intent described in the plan.
If any uploaded governance file contains different wording, update this map to match the actual text.

## Common collision zones and how to resolve

### A) "Feed names directly to AI" vs defensible claims
Risk: Over-claiming partnerships or privileged access.
Safe external phrasing: "Designed to be cited by AI systems" and "structured for AI retrieval and citation."
Internal phrasing can be stronger, but public copy should stay defensible.

### B) "Guaranteed first-page placement" scope creep
Risk: Readers interpret it as citywide ranking influence.
Fix: Always attach the scope clause: "within verified neighborhoods after approval."
Also always include: "This does not affect overall city ranking."

### C) Payments and editorial independence
Risk: Payment language conflicts with "editorial controls rank and inclusion."
Fix: Payment does not override editorial review. Payment only triggers deeper verification and neighborhood placement after approval.

### D) Monthly/Annual pricing presentation
Risk: Payment doc says toggle but older templates show an annual line item.
Fix: Enforce toggle only. No separate annual product or line item.

### E) Copy templates vs compliance rules
Risk: Templates include persuasive language that triggers compliance rejection.
Fix: Templates never override compliance. If a template conflicts, rewrite it to the stricter rule.
